** Fork status: Gitea API support

This fork tracks upstream Forge and carries an experimental read-only
Gitea API backend.  The implementation promotes Gitea repositories from
URL-only support to API-backed synchronization using Ghub's Gitea
transport.

Current Gitea support can:

- recognize Gitea repositories from remotes and host configuration;
- pull repository metadata;
- synchronize labels, milestones, assignees and collaborators;
- synchronize issues, pull requests and their comments;
- reuse the Gitea backend for Forgejo repositories.

Mutation commands are not implemented yet.  Creating, editing, closing
or merging topics from Forge still needs a follow-up implementation.

The =main= branch is the integration branch for this fork and is intended
to be mirrored to a GitHub repository for upstream pull requests.
